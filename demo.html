Favicons

The icon in the browser tab. One file per site, in the site's light accent with a white glyph, so it looks the same in a light and in a dark browser. A favicon cannot read the page's CSS, so it has no dark variant.

Each site ships it as a single-colour SVG (favicon.svg, or a data-URI <link rel="icon">). Shown for the current site:

Mobile header icon

The icon in the header at 560px and below. It is the same drawing as the favicon, but it reads the page's CSS, so it follows the site's own toggle: the light accent in the light theme and the dark accent in the dark theme, with the glyph in the paper colour.
